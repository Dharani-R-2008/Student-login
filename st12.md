# CareerHub

CareerHub is a Student Career and Placement Management System built using React.

## Features

- Student Login
- Student Registration
- Student Dashboard
- Job Search
- Job Applications
- Application Tracking
- Student Profile
- Skills Management
- Responsive Design

## Technologies

- React.js
- JavaScript
- HTML
- CSS
- React Router
- Git
- GitHub
